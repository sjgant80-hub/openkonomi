Why this is different from signing it

Signing proves who wrote it. It does not prove what it does — the formal treatment of this says so outright, and all 341 malicious skills could have carried a perfectly valid signature. The same paper reports a negative result for static information-flow analysis: on their corpus it caught nothing that plain pattern matching did not. And an audit of the whole defence landscape concludes that execution-layer enforcement — policy checked at operation time — is absent from most platforms.

So openkonomi asks a different question. Not "is this signed", but: does what this text reaches for match what it declared, and is that inside the grant it would run under? A skill that declares no network while instructing you to pipe a remote script into a shell is not a judgement call. It is a contradiction, and a machine can refuse a contradiction.

The budget is the part everyone leaves out

The capability lattice is well understood. What the literature keeps omitting is a ceiling: may call the network and may call the network forty thousand times are different powers. Here a grant carries both, a refused action is charged nothing, and delegation can only ever shrink — there is no path by which a sub-agent acquires a power its caller lacked.
