openkonomi

Set up an AI agent that cannot go rogue — in four steps, in this page, with nothing to install.

You decide what it may touch and how much it may spend. It gets a signed identity. Every tool you add is checked before it can run, and refused if it asks for more than it admitted to. No account, no key, nothing uploaded.

STEP 1

Name your agent

Any name. It goes on the identity so you can tell your agents apart later.

STEP 2

What is it allowed to touch?

Tick only what it genuinely needs. Anything you leave unticked is impossible for it — not discouraged, not warned about. Impossible.

STEP 3

How much may it do?

A ceiling it cannot cross. When it runs out, it stops — by arithmetic, not by good behaviour.

STEP 4

Add a tool — and watch it get checked

Paste a tool file (the SKILL.md format the open agent world already uses). openkonomi reads what it actually reaches for and compares it to what it declared. Anything that doesn't line up is refused and listed below.

STEP 5

Run it

A stand-in assistant proposes actions — including, on purpose, some it was never allowed. Watch what gets through, and watch the ceiling stop it.

What this page is, plainly. Everything above runs in your browser. The agent identity is real Ed25519 — the same kernel the tests run against — and its private key never leaves this tab. What this page does not yet do is connect to your email, your files, or a model provider: it sets up and proves the bounds, which is the part everyone else leaves until after the incident.
